## Tooling

### Support for my IDE?
For this project only [JetBrains' IntelliJ Idea][idea] is currently supported.

It has a good integration with [JetBrains Academy][jb_academy].
It can easily run test suite for the contained Hyperskill project.

### Build tool
**Note: if you are interested only in the last (6th) task** using <u>**maven**</u>,
go to the dedicated [child repo][child_repo].

The **basic build tool is gradle**, but the configuration files are very intricate,
 not suitable for reading or editing by average user.
They were provided by the [JetBrains Academy][jb_academy]
 and facilitate integration with JB Hyperskill platform.
